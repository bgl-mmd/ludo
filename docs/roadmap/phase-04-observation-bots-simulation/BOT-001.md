# BOT-001 — Example bots

**ID:** BOT-001
**Title:** Example bots (random, greedy)
**Phase:** 4
**Depends on:** DOMAIN-001

## Goal

Reference `BotFn` implementations (spec 06 §4).

## Scope

- `make_random_bot(seed: int | None = None) -> BotFn` — closure with its own seeded RNG; returns a random legal action or `None`.
- `make_greedy_bot() -> BotFn` — deterministic priorities: capture, enter on 6, move closest to home, move any.
- Both always return an element of `obs.legal_actions` or `None` when empty.

## Out of scope

- RL/MCTS bots, learning, self-play.

## Acceptance criteria

- Bots always return legal actions (or `None` when empty).
- `make_random_bot(seed)` is reproducible across runs.
- Greedy bot's choice is deterministic and follows its priority order.

## Tests

- `test_random_bot_always_returns_legal_action`, `test_greedy_bot_always_returns_legal_action`, `test_bot_cannot_return_action_not_in_legal_actions`, `test_bot_reset_between_games` (spec 09 §2.7).
