# SIM-002 — Batch simulation

**ID:** SIM-002
**Title:** Batch simulation
**Phase:** 4
**Depends on:** SIM-001

## Goal

Run many games, optionally in parallel (spec 07 §3).

## Scope

- `run_batch(bot_factories, config, seeds, num_workers=1)` — maps `run_simulation` over seeds; optional `multiprocessing.Pool`.

## Out of scope

- Statistics aggregation, history export.

## Acceptance criteria

- Batch returns one `GameResult` per seed.
- Parallel (`num_workers > 1`) results equal serial results.

## Tests

- `test_batch_simulation_completes`, `test_parallel_simulation_same_results` (spec 09 §2.9).
