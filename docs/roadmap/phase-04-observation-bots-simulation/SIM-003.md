# SIM-003 — Statistics aggregation

**ID:** SIM-003
**Title:** Statistics aggregation
**Phase:** 4
**Depends on:** SIM-001

## Goal

Fold results into aggregate statistics (spec 07 §5).

## Scope

- `aggregate(results) -> dict` with `games`, `win_rate`, `draws`, `avg_turns`, `avg_errors`.

## Out of scope

- Training, visualization, persistence.

## Acceptance criteria

- Statistics are correct for a small hand-computable result set.
- Division-by-zero handled for empty input (or documented).

## Tests

- `test_statistics_correctly_aggregate` (spec 09 §2.9).
