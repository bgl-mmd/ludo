# SIM-001 — Simulation runner

**ID:** SIM-001
**Title:** Simulation runner (vertical slice completion)
**Phase:** 4
**Depends on:** ENGINE-001, ENGINE-002, ENGINE-003, RULE-001, OBS-001, BOT-001

## Goal

A complete, deterministic, local game loop (spec 07 §1).

## Scope

- `run_simulation(bots, config, seed=None) -> tuple[GameResult, tuple[MoveRecord, ...]]`:
  - Create the RNG from the seed; `new_game`; loop while `not is_game_over`: roll, build observation for the current player, call the bot, apply the action, append the `MoveRecord`.
  - `game_id` derived from the seed for the observations.
- Same `bots + config + seed` ⇒ same result and history.

## Out of scope

- Batch execution, statistics, history export, competition runner.

## Acceptance criteria

- A game with two random/greedy bots completes and always terminates with a result.
- Determinism: two runs with the same seed produce identical results and logs.
- Every action is recorded; valid bots produce zero errors.

## Tests

- `test_game_completes_with_random_bots`, `test_game_always_has_a_winner`, `test_game_deterministic_with_same_seed`, `test_game_records_all_moves`, `test_game_no_errors_with_valid_bots` (spec 09 §2.5).
