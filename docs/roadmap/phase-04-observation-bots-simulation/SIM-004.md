# SIM-004 — History export, import, replay

**ID:** SIM-004
**Title:** History export, import, and replay
**Phase:** 4
**Depends on:** SIM-001

## Goal

Record and replay games (spec 07 §6).

## Scope

- `export_history(log) -> dict` (JSON-able), `import_history(data) -> tuple[MoveRecord, ...]`, and a `step_through(log)` iterator.

## Out of scope

- Rendering, analysis tooling.

## Acceptance criteria

- Round-trip: `import_history(export_history(log)) == log`.
- Replay reproduces the original game's move sequence.

## Tests

- `test_replay_matches_original_game`, `test_deterministic_replay`, `test_export_import_roundtrip` (spec 09 §2.9).
