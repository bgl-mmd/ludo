# OBS-001 — Observation builder

**ID:** OBS-001
**Title:** Observation builder
**Phase:** 4
**Depends on:** RULE-004, RULE-005, DOMAIN-002

## Goal

Build a player-relative `Observation` for the bot interface (spec 06 §2/§3, spec 05 §11).

## Scope

- `get_observation(state, player, config) -> Observation`:
  - Own and opponent token positions converted to `player`'s relative view.
  - `dice_value`, `consecutive_sixes`, `turn_number`, `game_id`.
  - `legal_actions` computed via `RULE-004`.
  - `game_state` string (`WAIT_FOR_YOU` / `WAIT_FOR_MOVE` / `END_*`), `game_over`, `is_your_turn`.
- No board/global coordinates leak into the observation.

## Out of scope

- Bots, the simulation loop, competition parsing.

## Acceptance criteria

- Observation matches spec 06 §2 fields.
- Opponent tokens appear in the observing player's relative coordinates.
- `legal_actions` is consistent with `RULE-004`; empty means no valid move.

## Tests

- Field correctness, opponent coordinate conversion, `test_invariant_player_cannot_see_other_player_coordinates`, `test_bot_receives_valid_observation` (spec 09 §2.7).
